# Assets

Demo images in this directory come from the YOLO ecosystem demo set (classic sample images
from the ultralytics repository):

- `bus.jpg` — a COCO dataset sample (street scene with a bus)
- `zidane.jpg` — a soccer scene, used as the canonical YOLO demo image since YOLOv5

Usage:

- Demo input for README examples and `scripts/infer.py`
- Real-image test data for `tests/test_export_parity.py` (onnx vs pt consistency)

Note: image copyright belongs to the original photographers; these files are used for
demonstration and testing only.
